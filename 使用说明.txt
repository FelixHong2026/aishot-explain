# AIShotExplain v2 —— 按 F9 截图，直接让 AI 解释

> 为「阅读外文书籍时快速理解截图内容」而做。
> 替代小旺AI截图的多级菜单：**一次 F9，一步到位。**

## v2 相比 v1 的改进（2026-11-18）

| 问题 | v1 | v2 |
|---|---|---|
| **慢**（要等几十秒） | glm-4.5v，**18.4 秒**才出第一个字 | 换 **glm-4v-flash**，**0.44 秒**出字、5.7 秒完成 |
| **回答是 `**#` 原始符号** | Text 组件原样显示 Markdown | **自动渲染**：标题加粗加大、列表变圆点、`代码`变等宽底色 |
| 干等没反馈 | 转圈到出结果才显示 | **流式**：文字一个个蹦出来，能立刻开始读 |

### 实测数据（同一张测试图）

```
模型            耗时        说明
glm-4v-flash   5.29 秒     ← v2 默认，免费
glm-4v-plus    4.47 秒     最快，但收费
glm-4v         4.64 秒
glm-4.5v      18.39 秒     ← v1 用的，推理模型，慢

流式（flash）：首字 0.37~0.44 秒，完成 4.3~5.7 秒
```

## 一、怎么用（3 步）

```
1. 双击「启动.bat」          ← 已在运行就不用再点
2. 按 F9                   ← 屏幕变暗，提示"拖拽选择要解释的区域"
3. 拖出一个框，松手          ← 等 5~20 秒，弹出窗口显示解释
```

**弹出窗口里可以：**
| 按钮 | 作用 |
|---|---|
| 继续追问（底部输入框） | 针对同一张图接着问，如"第二段再详细解释" |
| 复制答案 | 复制全部文字到剪贴板 |
| 重新截图 | 关掉窗口，重新按 F9 流程 |
| Esc | 关闭窗口 |

## 二、配置（config.json）

```json
{
  "hotkey": "F9",                    ← 想换就改这里，支持 F1~F12 / PrintScreen 等
  "provider": "zhipu",                ← zhipu（智谱，推荐）| openai（任意兼容服务）
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4v-flash",             ← 默认（快+免费）
  "api_key": "",                      ← 留空 = 自动读环境变量 ZHIPU_API_KEY
  "prompt": "...",                    ← 提示词，随便改
  "max_tokens": 2000,
  "temperature": 0.3
}
```

**改完重启程序生效**（任务管理器结束 pythonw.exe，再双击启动.bat）。

### 换模型

| 想用 | 配置 |
|---|---|
| **智谱 GLM（当前，推荐）** | `provider=zhipu` `base_url=https://open.bigmodel.cn/api/paas/v4` `model=glm-4v-flash`（默认，快且免费）或 `glm-4.5v`（慢但更详细） |
| 任意 OpenAI 兼容视觉模型 | `provider=openai` + 对应 `base_url` + `model` + `api_key` |

> ⚠️ **DeepSeek 不行**：实测 `deepseek-v4-pro` / `deepseek-flash` 会**静默忽略图片**
> （API 返回 200，但模型回答"无法读取这张图片"）。别浪费时间。

## 三、提示词推荐几种（改 config.json 的 prompt）

**读书用（默认）**
```
请解释这张图片里的内容：
1. 如果有外文，先给出中文翻译
2. 再解释文字的含义、涉及的背景知识或专业术语
3. 语言简洁，直接说要点，不要客套话
```

**只翻译**
```
把图片里的文字翻译成中文，保持原段落结构，不要加解释。
```

**学术/技术资料**
```
识别图片中的文字并解释：术语含义、公式推导思路、以及这段内容在讲什么。
```

**古文/文言**
```
识别图中的古文，给出白话文翻译，并解释生僻字词和典故出处。
```

## 四、技术说明

| 项 | 说明 |
|---|---|
| 依赖 | **零第三方包**：tkinter（界面）+ Pillow（截图，你环境已有）+ ctypes（全局热键） |
| 热键 | ctypes `RegisterHotKey`，不需要装 keyboard/pynput |
| 截图 | Pillow `ImageGrab`，支持多屏 |
| DPI | 启动时设 `SetProcessDpiAwareness(2)`，高 DPI 下选区坐标才准 |
| 日志 | `aishop.log`，出问题看这里 |
| 内存 | 常驻约 20~30 MB（tkinter 隐藏主窗口 + 热键线程） |
| 退出 | 任务管理器结束 `pythonw.exe` |

### 已知限制

1. **F9 与浏览器全屏冲突** —— 某些浏览器/游戏里 F9 会被本程序拦截。
   若冲突严重，把 config.json 的 `hotkey` 改成 `"F9"` 或 `"PAUSE"`。
2. **截图时屏幕会暗一下**（半透明遮罩），这是正常的选区界面。
3. **首次请求较慢**（智谱 GLM-4.5V 实测约 **18 秒**，纯文本模型更快）。
4. **不联网就不能用**（AI 解释必须走 API）。

# 附：Quicker 侧的配置（问题 A）

**Quicker 的配置文件 `quicker.db` 是加密的，无法用脚本修改**，必须在图形界面里配。
配置一次就好，之后永久生效。

## 配置步骤

```
① 打开 Quicker 设置
   托盘图标右键 → 设置    （或按 Quicker 默认的 Ctrl+Shift+空格 打开面板 → 齿轮）

② 进入「AI」
   左侧菜单找到 AI / AI 服务

③ 添加服务
   类型   ：OpenAI 兼容 / 自定义
   名称   ：智谱 GLM（随便起）
   地址   ：https://open.bigmodel.cn/api/paas/v4
   API Key：你的 ZHIPU_API_KEY（环境变量里那个，68f2e7c0 开头，32 位 + 点 + 16 位）
   模型   ：glm-4.5v

④ 关键一步：勾选「图片理解」任务场景
   官方文档原话："候选模型必须在 AI 设置中明确标记为支持图片输入。
                 能力为未知或不支持的模型不会满足本模块要求。"
   → 不勾这个，「AI 图片理解」模块用不了

⑤ 测试
   设置页通常有"测试"按钮，发个"你好"确认连通
```

## 然后做一个动作（约 2 分钟）

```
Quicker 面板 → 新建动作
  [步骤1] 截图
      模块：屏幕截图 / 交互截图
      选项：勾"贴到剪贴板"或保留图片变量
  [步骤2] AI 图片理解
      模块：ai-vision / AI 图片理解
      图片    ：上一步的图片输出（变量）
      问题或任务：请解释这张图片里的内容，先翻译外文再解释含义
      输出模式：交互调整   ← 关键！会弹出 Markdown 对话窗口，可继续追问
```

**配好后**：鼠标中键 → 点这个动作 → 拖框 → 弹窗出解释（和 AIShotExplain 效果一样，
但走 Quicker 的界面）。

## 六、两套方案怎么选

| | **AIShotExplain（本程序）** | **Quicker 动作** |
|---|---|---|
| 触发 | **F9 一个键** | 中键 → 再点一次动作 |
| 步数 | **1 步** | 2 步 |
| 换提示词 | 改 config.json | Quicker 里改 |
| 继续追问 | ✅ | ✅（交互调整模式） |
| 依赖 | Python + Pillow | Quicker |
| 已就绪 | ✅ **现在就能用** | ⚠️ 需你先在 GUI 配 AI |

**结论：先用 AIShotExplain（一步到位），Quicker 动作当备选。**
